# Netflix Content Analytics

An end-to-end data analytics project analyzing Netflix movies and TV shows using Python, SQL, and Power BI.

## Project Overview

This project explores Netflix content to understand:
- The distribution of Movies and TV Shows
- Content ratings
- Release-year trends
- Netflix content by type
- Overall content distribution

The project follows a complete data analytics workflow from raw data cleaning to interactive dashboard creation.

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- SQLite
- SQL
- Power BI
- Google Colab
- GitHub
